## 三、发布后跟踪

### Day 1-3 检查项
- [ ] Reddit 帖子是否被移除/标记 spam
- [ ] Facebook 群组是否被踢
- [ ] Quora 回答是否被折叠
- [ ] ML 论坛帖是否正常显示

### Day 5 检查项
- [ ] GA4 是否有新增流量来源（referral from reddit.com, facebook.com, quora.com）
- [ ] 博客页面是否有新增 PV
- [ ] 首页是否有新增检测请求

### 每周检查项
- [ ] 各渠道帖子的互动数据（评论、点赞、分享）
- [ ] 目录提交是否被审核通过
- [ ] 是否有负面反馈需要处理

| 风险 | 应对 |

| ML 论坛帖被删 | 避免过度推广，聚焦合规知识分享 |
