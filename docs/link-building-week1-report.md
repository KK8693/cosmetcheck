## 五、风险提示

1. **Product Hunt 发布风险** — 避免用假账号 upvote，PH 会检测并移除刷票
2. **Reddit 风险** — 严格遵守 "先价值后引导"原则，硬广可能被封号
3. **HARO 风险** — 回复必须真实专业，虚假信息会被记者拉黑
4. **Guest Post 风险** — 低质量博客的外链可能负面影响 SEO，严格筛选 DR > 40 的目标
